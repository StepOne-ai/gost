# gost

Навык (skill) для ИИ-ассистентов: оформление и проверка РПЗ, пояснительных записок, курсовых и отчётов по лабораторным работам в DOCX/PDF по ГОСТ 7.32-2017 и методичке кафедры ИУ6 МГТУ им. Н. Э. Баумана.

Не привязан к конкретной модели: формат – обычный Markdown с YAML-заголовком (`name`, `description`), поэтому подходит для Claude, ChatGPT/Codex, Gemini, Cursor, Qwen, DeepSeek и любой другой нейросети, которой можно дать инструкции или файл.

## Что внутри

- `SKILL.md` – сами правила:
  - ориентир по пунктам ГОСТ 7.32-2017 (поля, шрифт, заголовки, нумерация, подписи таблиц);
  - типографика: интервалы перед/после абзаца 0 пт, 6 пт перед подзаголовком сразу после таблицы или листинга, только короткое тире «–», дефис вместо тире, неразрывный пробел после тире в перечислениях, строчная буква после тире в подписях;
  - приложение с ТЗ: отдельный лист «ПРИЛОЖЕНИЕ А», титул ТЗ без номера, внутренняя нумерация ТЗ с 2 снизу по центру, «Листов N»;
  - список использованных источников с единым отступом номера и текста;
  - отчёты по лабораторным: титул, структура, диаграмма классов вместо схемы алгоритма для ООП, подписи, «Продолжение листинга/таблицы N», без пустых страниц;
  - точечная правка DOCX/PDF без поломки остальной вёрстки и проверка перед выдачей.
- `agents/openai.yaml` – метаданные для агентов, которые читают этот формат (название, краткое описание, промпт по умолчанию).
- `gost.zip` – готовый архив папки `gost/` для загрузки.

## Как подключить

### Через агента (проще всего)

Скопируй промпт и отправь агенту с доступом к терминалу и файлам (Claude Code, Codex, Cursor и т. п.):

```text
Склонируй https://github.com/StepOne-ai/gost и установи как скилл «gost».
1. Определи, где твоя среда хранит скиллы (Claude Code – ~/.claude/skills/,
   Codex – ~/.codex/skills/; для другой среды найди её каталог навыков или правил).
2. Скопируй туда папку gost с файлами SKILL.md и agents/ (без .git, README.md и gost.zip).
   Если скилл gost уже установлен – замени файлы новой версией.
3. Если у среды нет каталога навыков, добавь содержимое SKILL.md в правила проекта
   (rules / custom instructions).
4. Проверь, что SKILL.md читается и скилл виден в списке навыков, и напиши, куда установил.
```

Обновить до свежей версии – тот же промпт или коротко: «обнови скилл gost из https://github.com/StepOne-ai/gost».

В чатах без доступа к файлам (ChatGPT, Gemini, DeepSeek и т. п.) достаточно попросить: «прочитай https://github.com/StepOne-ai/gost/blob/main/SKILL.md и оформляй мой документ по этим правилам» – или приложить `SKILL.md` файлом.

### Вручную

| Где | Как |
|---|---|
| Claude (claude.ai, приложение) | Settings → Capabilities → Skills → загрузить `gost.zip` |
| Claude Code | распаковать в `~/.claude/skills/gost/` |
| Codex и другие агенты с поддержкой skills | положить папку `gost/` в каталог навыков агента (например, `~/.codex/skills/gost/`) |
| Cursor, Windsurf, Cline и т. п. | добавить содержимое `SKILL.md` в правила проекта (rules / custom instructions) |
| ChatGPT, Gemini, DeepSeek, любой чат | вставить `SKILL.md` в системный промпт / пользовательские инструкции или приложить файлом к диалогу со словами «оформи по этим правилам» |

Для работы с DOCX/PDF модели нужен доступ к файлам и инструментам (python-docx, LibreOffice или встроенные средства агента). Без них навык всё равно полезен как чек-лист нормоконтроля.

## Обновление архива

```bash
mkdir -p /tmp/pkg/gost && cp -r SKILL.md agents /tmp/pkg/gost/ && (cd /tmp/pkg && zip -rX gost.zip gost) && mv /tmp/pkg/gost.zip .
```
