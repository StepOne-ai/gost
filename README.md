# gost

Навык (skill) для Claude: оформление и проверка РПЗ, пояснительных записок, курсовых и отчётов по лабораторным работам в DOCX/PDF по ГОСТ 7.32 и методичке кафедры ИУ6 МГТУ им. Н. Э. Баумана.

## Состав

- `SKILL.md` – правила навыка: ориентир по ГОСТ 7.32-2017, типографика (интервалы 0 пт, 6 пт перед подзаголовком после таблицы или листинга, только «–», строчная буква после тире в подписях), список источников, отчёты по лабораторным (титул, структура, диаграммы классов, продолжение листингов и таблиц, без пустых страниц), точечная правка DOCX/PDF, проверка перед выдачей.
- `agents/openai.yaml` – метаданные для интерфейса агента.

## Установка

Заархивируй папку с `SKILL.md` и `agents/` как `gost/` в zip и загрузи в Claude: Settings → Capabilities → Skills.

## История

Каждое согласованное изменение правил – отдельный коммит (`git log`).
